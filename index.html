Your logs, on your own Cloudflare account.

Open Logs is a free, open-source log viewer you install with one command. Send logs over HTTP, then tail, search, chart and alert on them. Storage runs on Cloudflare Basin, so it stays affordable as you grow.

View on GitHub Get started 
# send a log from any app
curl https://logs.acme.dev/v1/logs \
  -H "Authorization: Bearer $SOURCE_TOKEN" \
  -d '{"level":"error",
       "message":"payment failed: gateway_timeout",
       "order_id":46346}'
13:50:55ERRORcheckoutpayment failed: gateway_timeout

Every project gets an overview dashboard out of the box.

Live tail and search

Watch logs arrive, filter by source, level or any field, and open an event to see everything it carried.

  • level = error, code:gateway_timeout, or plain text
  • A histogram of the selected range above the list
  • Copy an event as JSON, link to it, or see what happened around it

Dashboards without SQL

Pick a filter, a measure and a chart type. Counts, averages and p95, as numbers, bars, lines or pies.

  • Each number compares itself with the previous period
  • 15 minutes, 1 hour, 24 hours or 7 days
  • As many dashboards per project as you need

Alerts on any chart

Put an alert on a chart: when logs go above a number, or rise by a percentage, Open Logs opens an incident and calls your webhook.

  • Windows from 5 to 60 minutes
  • Quiet time after resolving, so you aren't paged twice
  • Incidents resolve themselves when things recover

Also included

Projects and sources

One project per product, one source per app, each with its own ingest token.

Team sign-in

Invite teammates with a link. Owner, admin and member roles, no extra service to run.

Simple HTTP ingest

Send one log or a batch of up to 10,000 from curl, JavaScript, Python, Go or anything else.

Saved views

Save a search to the sidebar and come back to it in one click.

Update and roll back

npm run update and npm run rollback keep your install current.

Your account, your data

Everything runs in your Cloudflare account. Nothing leaves it.

Why I built it

When Cloudflare launched Basin, I saw a great place to keep logs: serverless, affordable storage you can query with SQL. What it didn't have was a product on top. No way for an app to send logs safely, no log viewer, no charts, no team sign-in.

So I built a simple version and made it open source, as a way to give back to the community.

We just built this. You can fork it and build whatever you want.

Install

# needs a Cloudflare account on Workers Paid
git clone https://github.com/Adithya188288/open-logs.git open-logs
cd open-logs
npm run setup

Setup creates everything in your account, deploys the app and prints the address to sign in. The README covers sending logs, limits and updates.
